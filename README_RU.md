# OPDS Desk

[English README](README.md)

OPDS Desk — настольный клиент для Windows, предназначенный для просмотра и поиска книг в каталогах OPDS 1.x и их загрузки в локальную библиотеку.

Текущая версия приложения: **1.0.0**

## Обзор

OPDS Desk — локальное настольное приложение с серверной частью на Flask и интерфейсом на pywebview. Пользователь настраивает один OPDS-источник и выбирает каталог локальной библиотеки, в котором будут храниться загруженные книги.

Отдельный сервер приложения не требуется. Сетевой доступ необходим для подключения к настроенному OPDS-источнику и загрузки книг по предоставленным им URL.

## Совместимость

OPDS Desk — универсальный клиент для каталогов OPDS 1.x.

Приложение предназначено для работы со стандартными OPDS-сервисами и также
тестировалось с каталогами, использующими структуру OPDS, характерную для
Flibusta.

OPDS Desk является независимым проектом и не связан с Flibusta или другими
поставщиками каталогов, не поддерживается и не управляется ими. Пользователь
самостоятельно отвечает за соблюдение применимого законодательства и условий
использования подключаемых OPDS-сервисов.

## Возможности

- Первоначальная настройка и выбор каталога локальной библиотеки.
- Ручная настройка и проверка OPDS-источника.
- Просмотр каталогов OPDS 1.x на основе Atom-лент.
- Постраничная навигация по Atom-ссылкам, предоставленным источником.
- Поиск через OpenSearch при наличии поддерживаемого описания поиска.
- Переходы к связанным каталогам и разделам каталога.
- Выбор книг из результатов OPDS-поиска.
- Постоянная очередь загрузок на основе SQLite.
- Ручной запуск очереди, пауза, продолжение, изменение приоритета, повтор и удаление элементов.
- Настраиваемый планировщик очереди и минимальный порог свободного места на диске.
- Прогресс загрузки каждой книги и повторные попытки при временных ошибках.
- История очереди, сведения о запусках, экраны заданий и уведомления.
- Обнаружение книг, уже находящихся в локальной библиотеке.
- Группировка дублирующихся изданий и выбор предпочтительного издания.
- Загрузка EPUB и FB2, включая FB2 в ZIP-архивах.
- Проверка формата файла перед публикацией завершённой загрузки.

Просмотр OPDS-каталогов в настоящее время доступен только для чтения. Книги добавляются в очередь загрузок преимущественно из результатов OPDS-поиска.

## Поддерживаемые каталоги и форматы

Поддержка каталогов:

- OPDS 1.x на основе Atom-лент.
- OpenSearch Description 1.1, если он предоставляется настроенным источником.

Поддержка загрузки:

- EPUB.
- FB2 XML.
- FB2 в ZIP-архиве.

В настоящее время не поддерживаются следующие каталоги:

- Каталоги OPDS 2 на основе JSON.

В настоящее время не поддерживается загрузка книг в следующих форматах:

- PDF.
- DJVU.
- MOBI.

Список загрузок описывает форматы, обрабатываемые текущим модулем загрузки. OPDS-лента при этом может содержать метаданные или ссылки для других форматов.

## Требования

Для собранного приложения:

- Windows.
- Доступ к настроенному OPDS-источнику и его URL загрузки книг.
- Доступ на запись в выбранный каталог библиотеки.

Для разработки из исходников:

- Python 3.
- `pip`.
- `venv`.

Текущая версия разрабатывается и тестируется с Python 3.13. Репозиторий пока не определяет официальную минимальную версию Python или список поддерживаемых версий Windows. Настольный интерфейс предоставляется pywebview.

## Установка из исходников

Клонируйте репозиторий, создайте виртуальное окружение, установите зависимости и запустите приложение:

```powershell
git clone <repository-url>
cd <repository-directory>
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r .\requirements.txt
python .\app.py
```

Приложение также можно запустить без активации виртуального окружения:

```powershell
.\.venv\Scripts\python.exe .\app.py
```

## Первый запуск

1. Запустите OPDS Desk.
2. Выберите существующий каталог локальной библиотеки с доступом на запись.
3. Завершите первоначальную настройку.
4. Откройте настройки OPDS.
5. Введите абсолютный HTTP- или HTTPS-адрес OPDS.
6. Дождитесь проверки источника приложением перед его сохранением.
7. Вернитесь на главный экран и воспользуйтесь поиском или просмотром каталога.

Приложение не предоставляет OPDS-источник по умолчанию. Источник вводится пользователем вручную.

## Использование приложения

### Настройка OPDS-источника

Откройте настройки OPDS, введите абсолютный HTTP(S) URL и отправьте форму. OPDS Desk нормализует URL, получает корневую ленту и проверяет, что она является поддерживаемой Atom-лентой, прежде чем сохранить URL и название источника.

Одновременно может быть настроен только один источник. Текущий источник можно удалить на том же экране настроек.

### Поиск

Введите запрос на главном экране. Поиск доступен только в том случае, если настроенный источник предоставляет поддерживаемое описание OpenSearch или прямой шаблон поиска Atom. Если источник их не предоставляет, просмотр каталога остаётся доступным, но поиск использовать нельзя.

Результаты поиска могут занимать несколько страниц. Выбор сохраняется при переходе между страницами результатов в рамках текущего сеанса настольного приложения.

### Просмотр каталогов

Откройте настроенный каталог с главного экрана, чтобы просматривать его публикации, разделы навигации, связанные каталоги и ссылки пагинации. Представление полного каталога может пройти по цепочке страниц источника в пределах ограничения приложения.

Страницы каталога в настоящее время доступны только для просмотра и не предлагают прямых действий с очередью.

### Добавление книг в очередь

Выберите книги в результатах OPDS-поиска и режим формата:

- **Авто** предпочитает EPUB, а при его отсутствии — FB2.
- **EPUB** принимает только результаты со ссылкой загрузки EPUB.
- **FB2** принимает только результаты с поддерживаемой ссылкой загрузки FB2.

Отправленный выбор сопоставляется с данными книг, сохранёнными локальной серверной частью. Книги, уже имеющиеся в библиотеке, уже находящиеся в активной очереди или не имеющие поддерживаемого формата, пропускаются.

### Запуск загрузок

На экране очереди можно вручную запустить загрузку, приостановить её после текущего элемента, продолжить обработку, изменить приоритеты или удалить ожидающие элементы. Автоматические запуски можно включить для настроенного локального времени и смещения UTC.

Перед началом работы очередь проверяет настроенный минимальный объём свободного места на диске. Загрузки одновременно обрабатывает только один обработчик очереди.

### Наблюдение за очередью и историей

Экран очереди показывает прогресс текущего элемента и общее состояние. На дополнительных экранах доступны сводки запусков, история завершённых элементов, повтор ошибочных элементов, сохранённое состояние заданий и уведомления приложения.

## Локальные данные

При новой установке данные приложения сохраняются в:

```text
%LOCALAPPDATA%\OPDSDesk
```

Например:

```text
C:\Users\<User>\AppData\Local\OPDSDesk
```

Каталог может содержать:

- `config.json` — конфигурацию приложения, источника, первоначальной настройки и библиотеки.
- `jobs.json` — сохранённое состояние заданий.
- `queue.db` — элементы очереди, настройки планировщика, уведомления и историю запусков.
- `Library\` — каталог локальной библиотеки по умолчанию, если он выбран и используется.

Во время работы приложения SQLite также может создавать `queue.db-wal` и `queue.db-shm`. Пользователь может выбрать другой каталог библиотеки; в этом случае файлы книг записываются в него, а не в каталог `Library\` по умолчанию.

## Сетевое поведение

- OPDS-источники могут использовать HTTP или HTTPS.
- Учётные данные, встроенные в URL источника, отклоняются.
- Поддерживаются перенаправления HTTP.
- Используется стандартная для requests проверка TLS-сертификатов.
- Используется стандартное поведение requests в отношении системных прокси-серверов и переменных окружения.
- Разрешены OPDS-источники в частной или локальной сети.

Для источников, доступных через недоверенные сети, используйте HTTPS.

## Проверка загружаемых файлов

- Загрузки записываются во временные файлы.
- Незавершённые загрузки не публикуются как итоговые файлы библиотеки.
- Проверяются структура EPUB ZIP, метаданные и ссылки на файлы пакета.
- Разбирается неупакованный FB2 XML и проверяется его корневой элемент.
- Проверяется содержимое FB2 ZIP и извлечённый из него FB2.
- Применяются ограничения размера загрузки и извлечённого файла.
- Завершённые файлы атомарно публикуются по конечному пути.

## Сборка Windows EXE

PyInstaller является зависимостью сборки и не входит в `requirements.txt`. Перед сборкой установите PyInstaller отдельно в окружение разработки:

```powershell
python -m pip install PyInstaller
```

Сборка приложения в виде каталога, результат — `dist\OPDS-Desk\OPDS-Desk.exe`:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm .\OPDS-Desk.spec
```

Сборка приложения в виде одного файла, результат — `dist\OPDS-Desk.exe`:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm .\OPDS-Desk-OneFile.spec
```

## Тестирование

Проверка компиляции основного модуля и запуск полного набора модульных тестов:

```powershell
.\.venv\Scripts\python.exe -m py_compile .\app.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты охватывают разбор OPDS, обработку URL, OpenSearch и поиск, навигацию по каталогам, идентификацию элементов очереди и поведение обработчика, загрузку и проверку файлов, сохранение состояния и метаданные сборки.
